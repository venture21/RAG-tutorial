RAG Student Studio 1.2.0 — 2026-10-29
====================================

배포 범위
---------
PC용 웹 서비스·CLI, 설치 정의·잠금 파일, 환경 예시, 세 OS 안내, 오프라인 테스트만 포함합니다.
추가: ref_code/를 프로그램 폴더 안으로 이동하고 참고 채팅 코드 4개도 포함했습니다.
참고 코드의 .env 경로를 명시하고 DeepSeek/Gemma의 토큰 공급 콜백을 적용했습니다.
GitHub 공개용 .gitignore 허용 목록과 macOS·Linux·Windows 오프라인 CI를 추가했습니다.
PDF 0개. 실제 .env·키·인증 파일·DB·캐시·로그·업로드·가상환경·노트북 출력·개인 스크린샷·
기존 QA/평가 자료는 포함하지 않습니다. 수강생이 자신의 PDF와 Google Cloud 프로젝트·ADC를 준비합니다.
사용자의 기존 개인 설정 파일과 기존 DB·캐시는 삭제하지 않았습니다.

검토 사항별 조치
----------------
R01: 실제 환경 파일은 ZIP에서 제외하고 개인 값 없는 .env.example만 포함합니다.
R02: 기본 바인딩 127.0.0.1, 허용 Host와 동일 Origin 검사, PDF 폴더 경계·링크 검사,
     업로드 형식·크기·페이지 수 검증을 추가했습니다. 로컬 실습용입니다.
R03: 독립 pyproject.toml, 공용 PyPI의 uv.lock, 해시가 포함된 requirements.txt를 제공합니다.
R04: CLI는 공통 RAGService와 ADC를 사용하며 개인 프로젝트 기본값·API 키 자동 전환을 제거했습니다.
R05: 앱 팩터리·서비스 주입과 지연 초기화를 적용했습니다. 테스트는 임시 데이터만 사용합니다.
R06: 질문·문서명·경로·모델 문자열을 HTML/속성에 넣기 전 이스케이프합니다.
R07: 허용 목록으로만 패키징해 실행 데이터와 개인 자료가 섞이지 않게 했습니다.
R08: DB별 임베딩 모델·차원을 검증하고 한 번 계산한 질문 벡터를 검색에 재사용합니다.
R09: 안정된 문서·페이지·청크 ID와 페이지 manifest를 저장합니다. 해당 페이지만 트랜잭션으로 교체합니다.
     부분 업로드에 없는 페이지는 삭제하지 않습니다. 저장 중 실패해도 이전 인덱스가 유지됩니다.
R10: OCR 실패를 문서 본문으로 저장하지 않고 작업 실패로 처리합니다.
R11: 텍스트/스캔 혼합 PDF는 필요한 페이지만 OCR하고 원래 페이지 순서로 합칩니다.
R12: Model Garden은 토큰 공급 콜백을 사용해 실제 HTTP Authorization에 갱신 토큰을 반영합니다.
R13: 캐시 v2는 문서/질문 작업 유형과 출력 차원 설정을 구분합니다.
R14: 원본 저장소의 보조 PDF 생성기는 공통 폰트 탐색으로 개인 Mac 경로를 제거했습니다.
     보조 PDF 생성기·폰트·생성 PDF는 이 서비스 ZIP에는 포함하지 않습니다.
R15: 원본 저장소의 Weaviate 가이드 생성기에서 Python 3.11 f-string 문법 문제를 수정했습니다.
     해당 별도 실습은 이 ZIP 범위에서 제외했습니다.
R16: 메인 데이터 경로를 프로그램 기준 data/로 통일하고 문서 링크·OS별 실행 명령을 정리했습니다.
     기존 OCR 캐시에 의존하는 과거 평가기·저장 결과와 개인 경로가 담긴 보조 자료는 배포에서 제외합니다.
R17: 시작 ping과 검색 중복 임베딩을 제거하고 OCR usage를 집계합니다. 비용 UI는 실습 예시·추정치로
     표시합니다. 실제 가격·청구액·SDK 내부 재시도 전체를 보증하지 않습니다.

추가 조치
---------
SQLite 연결을 명시적으로 닫아 Windows 파일 잠금 문제를 줄였습니다.
질문 길이, 청크/오버랩, 페이지 한도를 검증합니다. 서비스 작업은 잠금으로 직렬화합니다.
PC 최소 폭 1280px, 좌측 설정 320px와 우측 2열 카드는 유지했습니다.
오류 응답에서 원시 클라우드 예외·인증 정보가 노출되지 않도록 공통 안내를 사용합니다.

검증과 한계
-----------
macOS Python 3.11의 새 가상환경에 잠금 파일의 의존성을 해시 검증으로 설치하고 의존성 검사를 수행합니다.
외부 요청을 차단한 오프라인 테스트 38개에 인증·캐시·갱신·롤백·경로/Origin·OCR·토큰 갱신·참고 코드를 포함합니다.
Windows 이벤트 루프가 사용하는 표준 socketpair 초기화만 허용하며 일반 로컬·외부 연결 차단도 검증합니다.
JavaScript 문법, HTML 이스케이프, PC 레이아웃 규칙도 별도로 검사합니다.
실제 배포 ZIP을 다시 풀어 오프라인 테스트와 브라우저 표시를 확인합니다.
Windows·Linux 실제 기기 실행, 실제 클라우드 OCR·임베딩·답변과 청구 금액은 검증하지 않았습니다.
해당 플랫폼의 공식 wheel 제공 여부와 설치 환경에 따라 추가 빌드 도구가 필요할 수 있습니다.
